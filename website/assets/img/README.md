# assets/img

- `logo.png`     — logo header (tinggi ~64px, latar telus)
- `hero.jpg`     — gambar utama (1200 × 900)
- `team.jpg`     — gambar pasukan (1000 × 800)
- `favicon.png`  — ikon tab (64 × 64)
- `og-image.jpg` — pratonton kongsi WhatsApp/Facebook (1200 × 630)
